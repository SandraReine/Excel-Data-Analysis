# Excel Sales & Retail Data Analysis Project

## Overview

This project was completed during my Data Technician Bootcamp and showcases the use of Microsoft Excel to analyse retail and sales datasets. The project focused on data cleaning, organisation, analysis, reporting, and visualisation to identify trends and generate business insights.

## Skills Demonstrated

### Excel Functions & Formulas
- SUM()
- SUMIF()
- AVERAGE()
- AVERAGEIF()
- DATE()
- MONTH()
- YEAR()
- UNIQUE()
- VLOOKUP()
- SWITCH()

### Data Analysis
- Data filtering and sorting
- Sales and commission calculations
- Customer and product performance analysis
- Sales categorisation using logical functions
- Trend identification within retail datasets

### PivotTables
- Created PivotTables to summarise large datasets
- Analysed sales by country, county, product, age group, and gender
- Compared customer segments and regional performance
- Generated business insights from aggregated data

### Data Visualisation
- Created line charts to compare revenue and profit trends
- Built column charts to analyse product sales by country
- Designed pie charts to visualise revenue by customer age group
- Presented findings using clear and effective visualisations

## Project Activities

### Retail Sales Dataset
- Applied filters and sorting techniques to explore customer data
- Calculated total and average commission values using formulas
- Analysed transaction data to identify patterns and trends

### Bike Sales Analysis
- Used PivotTables to analyse customer purchases across countries
- Investigated sales performance by age group and gender
- Identified key market trends and customer demographics

### Product Sales Volume Analysis
- Built PivotTables to summarise product sales by county
- Used the SWITCH function to classify sales volumes:
  - High (>600)
  - Medium (300-600)
  - Low (<300)

## Key Findings
- Identified purchasing patterns across different customer age groups.
- Compared revenue and profit performance over time.
- Analysed product demand across multiple regions.
- Turned raw sales data into actionable business insights using PivotTables and charts.
