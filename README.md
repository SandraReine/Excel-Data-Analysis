# 📊 Excel Sales & Retail Data Analysis Project

## 🚀 Overview

This project was completed during my **Data Technician Bootcamp** and showcases the use of **Microsoft Excel** to analyse retail and sales datasets. The project focused on data cleaning, organisation, analysis, reporting, and visualisation to identify trends and generate meaningful business insights.

## 📂 Project Activities

### 🛍️ Retail Sales Dataset
- Applied filters and sorting techniques to explore customer data
- Calculated total and average commission values using formulas
- Analysed transaction data to identify patterns and trends

### 🚴 Bike Sales Analysis
- Used PivotTables to analyse customer purchases across countries
- Investigated sales performance by age group and gender
- Identified key market trends and customer demographics

### 💻 Product Sales Volume Analysis
- Built PivotTables to summarise product sales by county
- Used the `SWITCH()` function to classify sales volumes:

| Sales Volume | Category |
|-------------|-----------|
| > 600 | 🔥 High |
| 300 - 600 | ⚡ Medium |
| < 300 | 📉 Low |
